Permission Settings

Role-based access control and system authorization overview.

Role-Based Access Control Overview

Comprehensive review of role permissions for Head Mam/Sir, HOD, and Student.

Role 1: Head Mam/Sir Super Admin

Highest-level administrator with unrestricted authority.

  • ✅ Full access to all 15 system features
  • ✅ Add, edit, and delete events
  • ✅ Configure role-based permissions matrix
  • ✅ Manage and assign multiple payment QR codes
  • ✅ Clear payment records & export Excel workbooks
  • ✅ Customize website branding, name, logo, & colors
Role 2: HOD Department Access

Department-level access configured and delegated by Head Mam/Sir.

  • ✅ View permitted events and registration counts
  • ✅ View participant and attendee information
  • ✅ Access offline walk-in registration (when permitted)
  • ✅ View dashboard analytics summaries
  • ❌ Cannot modify payment QR codes or website branding
  • ❌ Cannot clear system payment transaction logs
Role 3: Student Participant

Student-level access for event exploration and registration.

  • ✅ Browse live technical and non-technical events
  • ✅ Register online for events
  • ✅ Access assigned payment QR code for registration
  • ✅ View personal registration details and reference IDs
  • ❌ Restricted from administrative dashboard and settings
  • ❌ Restricted from viewing private attendee lists
